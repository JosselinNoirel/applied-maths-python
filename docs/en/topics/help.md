## Source de documentation

Here are the main official documentation sources to prioritize.

### Python

- [Official Python documentation](https://docs.python.org/3/) — main documentation portal.
- [Python tutorial](https://docs.python.org/3/tutorial/) — a progressive introduction to the language.
- [Python standard library](https://docs.python.org/3/library/) — documentation for built-in functions and modules such as `math`, `statistics`, and `random`.
- [Python language reference](https://docs.python.org/3/reference/) — precise description of Python’s syntax and semantics.
- [General index](https://docs.python.org/3/genindex.html) — alphabetical index of functions and concepts.
- [PEP 8](https://peps.python.org/pep-0008/) — style conventions for Python code.
- [PEP 257](https://peps.python.org/pep-0257/) — conventions for docstrings.

### NumPy

- [NumPy documentation](https://numpy.org/doc/stable/) — main documentation portal.
- [NumPy user guide](https://numpy.org/doc/stable/user/) — arrays, indexing, data types, broadcasting, copies, and views.
- [NumPy fundamentals for beginners](https://numpy.org/doc/stable/user/absolute_beginners.html) — an accessible introduction.
- [NumPy quick-start guide](https://numpy.org/doc/stable/user/quickstart.html) — condensed presentation of common operations.
- [NumPy API reference](https://numpy.org/doc/stable/reference/) — detailed signatures and behaviour of NumPy functions.
- [NumPy general index](https://numpy.org/doc/stable/genindex.html) — alphabetical index.
- [NumPy tutorials](https://numpy.org/numpy-tutorials/) — guided examples and notebooks.

For precise information about functions such as `numpy.linspace`, `numpy.linalg.solve`, or `numpy.fft.fft`, the API reference is usually the best source.

### Matplotlib

- [Matplotlib documentation](https://matplotlib.org/stable/) — main documentation portal.
- [Quick-start guide](https://matplotlib.org/stable/users/explain/quick_start.html) — figures, axes, curves, legends, and annotations.
- [Matplotlib user guide](https://matplotlib.org/stable/users/index.html) — explanations organized by topic.
- [Matplotlib tutorials](https://matplotlib.org/stable/tutorials/index.html) — guided learning material.
- [Example gallery](https://matplotlib.org/stable/gallery/index.html) — plots accompanied by their source code.
- [Matplotlib API reference](https://matplotlib.org/stable/api/index.html) — exhaustive documentation for functions and objects.
- [`matplotlib.pyplot` reference](https://matplotlib.org/stable/api/pyplot_summary.html) — functions such as `plot`, `scatter`, `xlabel`, `legend`, and `show`.
- [Plot types](https://matplotlib.org/stable/plot_types/index.html) — visual overview of the available plot types.

For Matplotlib, the example gallery is often the best starting point: find a plot resembling the desired result, then consult the API reference for precise details.
